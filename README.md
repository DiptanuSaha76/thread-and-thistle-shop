# Remix of Fabric Folio Ecommerce

Read the complete design.md file and carefully study all the
provided YEARTH STORE UI reference screenshots.

Implement the complete responsive e-commerce clothing website
according to the design specification.

Build every listed page for both mobile and desktop.
Maintain consistent branding, typography, spacing, product cards,
navigation, and reusable components.

Make all UI controls functional, including product variants,
filters, sorting, wishlist, cart, checkout, and order management.

Do not create static mockup screens. Implement a working,
responsive React application using the project's existing stack.
